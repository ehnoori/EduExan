Four supported question types

choiceMultiple choice: Write options in the Option columns; at least two options.
numberNumber: پاسخ Number نمونه را ثبت کنید.
textText: Enter a sample answer in the file.
projectProject: پاسخ بلی/خیر و نام Project.
Important notes
  • Complete the Question and CorrectAnswer columns.
  • In the Type column, enter one of the four supported types.
  • For Multiple choice questions, specify the correct answer with an option letter such as A.
  • If the Type column is empty, the question is treated as Text.
